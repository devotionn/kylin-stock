## 2. 建议测试数据

为保证查询、组合筛选、库存分布和导出均可验证，建议现场先建立以下测试数据。名称可按客户习惯替换，但应保留“不同单位、不同位置、不同去向、不同时间”的覆盖面。

| 对象 | 建议数据 |
| --- | --- |
| 计量单位 | 个、箱、kg |
| 存放位置 | 一号仓、二号仓 |
| 物资 A | 网线 / 箱 / 一号仓 |
| 物资 B | 螺丝 / 个 / 二号仓 |
| 物资 C | 清洁剂 / kg / 一号仓 |
| 入库 A | 网线 10 箱，来源“供应商甲” |
| 入库 B | 螺丝 100 个，来源“供应商乙” |
| 入库 C | 清洁剂 20 kg，来源“供应商甲” |
| 出库 A | 网线 3 箱，去向“一车间” |
| 出库 B | 螺丝 20 个，去向“维修组” |

正式业务数据存在时，不要为了测试随意污染客户台账。优先在首次上线、空库阶段测试；如果必须在已有正式库上测试，使用明确带“验收测试”标记的物资/备注，并在客户确认后保留或按业务规则处理，禁止直接修改 SQLite 文件删除流水。

# 3. V1.1 业务验收场景

每个场景应记录：`通过/失败/阻塞`、实际结果、截图或导出文件名。任何“失败”都必须形成问题记录，不以口头说明代替。

## AC-01 目标机安装与启动

**操作**

1. 在目标 ARM64 麒麟设备安装正式 `.deb`。
2. 确认系统应用菜单/桌面入口显示“物资管理系统”。
3. 双击启动。
4. 关闭后再次启动。

**预期**

- 安装无包格式或架构错误。
- 中文入口名称正确。
- 主窗口正常打开，无白屏、闪退和缺失动态库提示。
- 关闭/重开正常。

**证据**：安装终端输出、应用菜单截图、主界面截图。

- [ ] 通过

## AC-02 新增与维护物资

**操作**：新增“网线”，选择单位、分类/位置并填写备注；再编辑备注或默认位置。

**预期**：保存成功，列表立即可见，编辑后信息正确；不要求用户填写商品编号。

- [ ] 通过

## AC-03 同名物资歧义拦截

**操作**：再次创建同名“网线”。

**预期**：系统明确拒绝重复名称；如果原记录已停用，应提示启用原物资，而不是生成第二条同名记录。

- [ ] 通过

## AC-04 入库闭环

**操作**：对“网线”入库 10 箱，填写业务时间、来源/相关单位、位置、经办人和备注。

**预期**：

- 保存成功；
- 当前库存增加 10；
- 出入库明细新增一条 IN 流水；
- 业务时间、来源、位置、数量、单位等信息正确。

- [ ] 通过

## AC-05 出库闭环与去向记录

**操作**：将“网线”出库 3 箱，去向填“一车间”。

**预期**：

- 保存成功；
- 当前库存从 10 变为 7；
- 明细新增一条 OUT 流水；
- “一车间”进入历史记录，并可用于后续筛选和导出。

- [ ] 通过

## AC-06 出库去向必填

**操作**：尝试出库但不填写去向。

**预期**：系统拒绝保存，库存不变，不产生 OUT 流水。

- [ ] 通过

## AC-07 库存不足保护

**操作**：当前库存 7 箱时尝试出库 8 箱。

**预期**：明确提示库存不足；库存仍为 7；不得产生失败操作对应的业务流水。

- [ ] 通过

## AC-08 当前库存与物资分布

**操作**：查看当前库存及库存物资分布。

**预期**：物资名称、位置、数量、单位等匹配已发生的入出库；同一物资若存在多个位置，应按位置分别展示余额。

- [ ] 通过

## AC-09 按物资名称查询

**操作**：在明细/台账页按“网线”筛选。

**预期**：只显示与网线匹配的历史记录；清空条件后恢复全部结果。

- [ ] 通过

## AC-10 按时间范围查询

**操作**：设置开始时间和结束时间，覆盖部分测试流水。

**预期**：只返回时间范围内记录，边界行为与界面提示一致。

- [ ] 通过

## AC-11 按相关单位查询

**操作**：按“供应商甲”等已录入单位筛选。

**预期**：只返回对应单位的流水。

- [ ] 通过

## AC-12 按出库去向查询

**操作**：筛选去向“一车间”。

**预期**：返回对应 OUT 流水，不混入其他去向记录。

- [ ] 通过

## AC-13 入库/出库类型查询

**操作**：分别选择 IN / OUT（界面中文可显示为入库/出库）。

**预期**：结果业务类型严格匹配筛选条件。

- [ ] 通过

## AC-14 多条件组合查询

**操作**：同时设置物资名称 + 时间范围 + 类型 + 单位/去向中的至少一个条件。

**预期**：结果满足全部条件的交集；改变任一条件后结果同步变化。

- [ ] 通过

## AC-15 “查询什么，就导出什么”

**操作**：保留 AC-14 的组合条件，点击“导出当前查询结果”。

**预期**：

- 成功保存 `.xlsx`；
- 文件中的数据行与当前页面筛选结果逐行核对一致；
- 不偷偷导出筛选之外的全部历史数据；
- 文件名具备可识别的业务含义和时间信息。

**证据**：页面截图 + 导出文件。

- [ ] 通过

## AC-16 出入库明细与库存分布独立导出

**操作**：分别导出出入库明细、当前库存/库存物资分布。

**预期**：每组结果都能独立保存为表格文件，列名、数量、单位、位置、去向等符合页面业务语义。

- [ ] 通过

## AC-17 麒麟办公软件打开 XLSX

**操作**：使用客户目标机实际办公套件打开 AC-15/16 生成的 `.xlsx`。

**预期**：文件可正常打开；中文不乱码；日期、数量、表头可读；没有“文件损坏”提示。

> 此项必须在客户实际办公套件验证，不能以开发机 Microsoft Excel 正常打开代替。

- [ ] 通过

## AC-18 表格统一居中与中文输入

**操作**：逐页查看物资列表、库存、出入库明细、查询结果、库存分布，并现场使用麒麟中文输入法录入物资名、去向、备注。

**预期**：

- 表头居中；
- 默认单元格居中，包括物资名称；
- 长文本仍可识别；
- 中文输入、删除、编辑和保存正常。

- [ ] 通过

## AC-19 手动/年度备份与恢复

**操作**

1. 记录当前库存和流水数量。
2. 创建即时备份。
3. 创建当前年度归档备份。
4. 新增一条明显可识别的测试流水。
5. 执行“从备份恢复”，确认恢复提示。
6. 恢复后再次核对库存/流水。

**预期**：

- 备份文件可选目录保存并可复制；
- 年度备份名称/记录清晰；
- 恢复前有明确确认；
- 恢复后回到备份时状态；
- 被恢复数据库通过完整性检查；
- 系统恢复前自动安全副本机制不破坏原有效数据；
- 失败时有明确错误，不静默吞掉异常。

**证据**：备份文件、恢复前后截图、必要时运行 evidence 脚本记录 DB `user_version/quick_check`。

- [ ] 通过

## AC-20 退出、重启与离线持久化

**操作**

1. 完成若干业务操作。
2. 正常关闭软件。
3. 断网后重新打开，执行查询、导出和本地备份。
4. 重启银河麒麟电脑。
5. 再次启动软件并核对库存、历史流水、物资资料。

**预期**：

- 核心业务不依赖互联网；
- 软件退出/系统重启后数据不丢失；
- 数据库可正常升级/打开；
- 库存余额与历史流水保持一致。

- [ ] 通过
